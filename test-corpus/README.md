# Test Corpus

60 small PDFs used by unit, integration, and end-to-end tests. Every file is generated by
[`generate.mjs`](generate.mjs) from scratch and is licensed under Apache-2.0 like the rest of
the project. No third-party PDFs are included yet; see `SOURCES.md` before adding any.

| Category     | What it covers                                                                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `normal/`    | Text, standard fonts, vector graphics, images with transparency, bookmarks, links, annotations, AcroForm fields, page labels, metadata, tagged PDF, 1,000 pages |
| `versions/`  | PDF 1.3, 1.4, 1.7, 2.0 headers                                                                                                                                  |
| `geometry/`  | Rotated pages, mixed sizes, tiny and maximum-size pages, CropBox, UserUnit                                                                                      |
| `structure/` | Object streams with xref streams, linearized, incremental update                                                                                                |
| `encrypted/` | RC4-40, RC4-128, AES-128, AES-256, owner-password-only, Unicode password                                                                                        |
| `malformed/` | Truncated, missing or wrong xref, junk before header, bad stream length, missing objects, cyclic page tree, not a PDF, empty                                    |
| `malicious/` | JavaScript actions, launch and submit-form actions, auto-open URL, embedded executable, image and Flate bombs, deep nesting, fake page count, XFA               |

## Manifest

`manifest.json` lists every file with its SHA-256 and expected behaviour:

- `"opens": true, "pages": N`: the renderer opens it and reports N pages.
- `"opens": "<code>"`: opening fails with that `OpenError` code. For encrypted files,
  `password` is the password that opens them.

Tests fail if a file's hash changes, so the corpus can't drift silently.

## Regenerating

Requires Node 24 and `qpdf`.

```sh
node test-corpus/generate.mjs
```

AES-256 encryption uses a random key, so those three files change on every run; all other
files are byte-for-byte reproducible. Commit regenerated files only when you intend to
change the corpus.

Damaged and hostile files don't have hand-written expectations. Their expected behaviour
is what the renderer did when they were added, after review:

```sh
CORPUS_OBSERVE=1 node test-corpus/generate.mjs
node --experimental-transform-types test-corpus/observe.mjs   # writes observed.json
node test-corpus/generate.mjs
```
